# 🎓 FastAPI Student Management System

A backend REST API built with **FastAPI** that manages student records using **PostgreSQL** and **SQLAlchemy**. This project follows a clean project structure and demonstrates industry-standard backend development practices.

---

## 📂 Project Structure

```text
FASTAPI_PRACTICE/
│
├── models/
│   └── student.py
│
├── routers/
│   └── student.py
│
├── schemas/
│   └── student.py
│
├── database.py
├── create_db.py
├── main.py
├── .env
├── .gitignore
├── requirements.txt
└── README.md
```

## 🛠️ Tech Stack

- Python 3.x
- FastAPI
- PostgreSQL
